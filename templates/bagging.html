Bagging (Bootstrap Aggregating)

Bagging es una técnica fundamental de ensemble learning diseñada para reducir la varianza y mejorar la estabilidad de los modelos de machine learning. Al entrenar múltiples modelos base de forma independiente y paralela, y combinar sus predicciones, se logra un modelo final más robusto y generalizable.

Ventajas Estratégicas

  • trending_down Reducción de varianza — ideal para modelos con alta capacidad como árboles profundos.
  • speed Paralelizable — entrenamiento simultáneo en múltiples núcleos/GPUs.
  • shield Robustez — resistente a outliers y ruido en los datos de entrenamiento.
  • insights Importancia de características — permite analizar la relevancia de cada variable.

Limitaciones

  • visibility_off Interpretabilidad — el modelo final es una "caja negra" difícil de explicar.
  • memory Coste computacional — requiere más memoria y tiempo que un modelo simple.
  • link Correlación entre modelos — si los modelos base están muy correlacionados, la reducción de varianza es limitada.
  • scale Modelos base débiles — con modelos muy simples, el beneficio agregado es marginal.

Fundamento Teórico del Bagging

El Bagging (abreviatura de Bootstrap Aggregating) se basa en el principio estadístico del muestreo bootstrap, introducido por Bradley Efron en 1979. La técnica busca reducir la varianza del modelo promediando las predicciones de múltiples estimadores entrenados en diferentes subconjuntos del conjunto original. Esta estrategia es particularmente efectiva cuando el modelo base tiene alta varianza y bajo sesgo, como los árboles de decisión profundos. El resultado es un modelo que generaliza mejor en datos no vistos, evitando el sobreajuste sin sacrificar significativamente la capacidad predictiva.
