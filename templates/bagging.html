Bagging (Bootstrap Aggregating)

El método de Bagging es una técnica fundamental en el aprendizaje por conjuntos (ensemble learning) diseñada para mejorar la estabilidad y precisión de los algoritmos de machine learning utilizados en la clasificación y regresión estadística. Al combinar múltiples modelos base independientes, reduce significativamente la varianza y ayuda a evitar el sobreajuste.

Mecanismos Principales

Bootstrapping

Muestreo estadístico con reemplazo. Se generan múltiples subconjuntos de datos a partir del dataset original. Cada modelo base se entrena con un subconjunto diferente, asegurando diversidad en el aprendizaje.

Aggregating

Combinación de las predicciones de todos los modelos base. Para problemas de clasificación, se suele usar la "votación mayoritaria". Para regresión, se calcula el "promedio" de las predicciones.

Modelo Destacado

forest

Random Forest

La aplicación más famosa de Bagging utilizando árboles de decisión como modelos base. Introduce aleatoriedad adicional al seleccionar un subconjunto aleatorio de características en cada división del nodo, descorrelacionando aún más los árboles.
